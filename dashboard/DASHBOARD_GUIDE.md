# Dashboard Build Guide

Import `data/used_cars_demo.csv` into Power BI or use the included Streamlit app.

## Page 1 — Executive Overview
Cards: listings, average price, median price, average mileage.
Charts: average price by brand, price distribution, listings by fuel.

## Page 2 — Depreciation
Charts: price vs age, price vs kilometers, average price by age band.

## Page 3 — Market Segments
Charts: fuel, transmission, owners, location and brand/model comparisons.

## Page 4 — Prediction
Use the Streamlit predictor included in `app.py`, or build Power BI input/output around the saved model.
